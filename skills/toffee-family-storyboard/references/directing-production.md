# Toffee Family 导演执行与生产规范

在创建或审查分镜表时完整读取本文件。本文件负责场面调度、表演节拍、对白语速、交付模式和机械门禁；`storyboard-visual-style.md` 只负责视觉粗草风格。

## 一、任务开始先锁定交付模式

在拆镜前记录以下配置。用户未指定时，使用 `shot-card + gray-rough + 16:9`。

### 故事板交付模式

- `shot-card`：每个最终镜头一张决定性定帧，镜号与图片一一对应。
- `group-sheet`：按用户已经指定的情景分组制作合页，每页 4–6 宫格。该模式只消费现有分组，不自行定义或新增“段”字段。
- `hybrid`：关键揭示、情绪转折和复杂调度镜头单独成页，其余镜头按现有分组合页。

### 视觉模式

- `pure-line`：纯白底、纯黑轮廓线；禁止灰调、灰洗、色块、阴影、排线和实心填色。
- `gray-rough`：纯白或中性浅灰纸面，黑白中性灰动画粗草；禁止任何彩色色相和完整明暗塑造。

### 页面映射

每个输出页面都必须先建立映射，禁止先画后补：

```markdown
页面ID：P001
交付模式：shot-card / group-sheet / hybrid
来源分组：用户已有分组ID；没有则填“无”
对应镜号：1–4
宫格数：4
阅读顺序：左上 → 右上 → 左下 → 右下
逐格映射：格1→镜1；格2→镜2；格3→镜3；格4→镜4
对应对白ID：D001–D003
```

`group-sheet` 与 `hybrid` 的每格只呈现一个决定性静态瞬间。一个格可以对应一个合并长镜头，但不得把长镜头的多个时间状态同时画入一格。

## 二、场面调度与空间连续性

### 场景空间表

每进入一个新场景，先输出场景空间表，再写镜头：

```markdown
| 场景ID | 主轴线 | 角色屏幕侧 | 出入口 | 关键道具位置 | 初始状态 |
|--------|--------|------------|--------|--------------|----------|
| S01 | 沙发—落地窗 | 小吉左、皮皮右 | 猫门在画面右侧 | 鳄鱼在沙发前 | 破洞、棉花外露 |
```

### 分镜表连续性字段

每个镜头必须填写：

- **场面调度**：谁从哪里移动到哪里；谁保持不动；动作先后顺序。
- **连续性锚点**：主轴线、角色屏幕侧、视线方向、出入口和关键道具方位。
- **道具状态**：镜头开始状态 → 镜头结束状态。

### 空间硬门禁

1. 未说明原因不得跨越 180 度轴线。
2. 越轴必须通过中性正面镜头、可见的摄影机过轴或角色穿越轴线完成，并在画面栏写出过程。
3. 角色离开画面的方向必须与下一镜进入方向相容；若时间或空间跳跃，必须提供建立镜头或声音桥。
4. 视线方向必须与被看对象的屏幕位置一致。
5. 道具结束状态必须成为下一镜的开始状态；破损、开关、装入、取出、移动和所有权变化都要登记。
6. 同屏默认只有一个主要动作。其他角色只能承担倾听、反应、等待或不争夺注意力的次要动作。
7. 任一空间硬门禁失败，直接打回，不进入量化评分。

## 三、表演节拍与视听时码

对白逐字保留不等于整句只写进“声音”栏。每个含对白、连续动作或关键反应的镜头必须建立镜内节拍。

```markdown
| 镜内时码 | 声音 | 说话者表演 | 倾听者反应 | 画面焦点 | 声音剪辑 |
|----------|------|------------|------------|----------|----------|
| 0.0–1.2s | 小吉：“让我看看。” | 身体前倾 | 皮皮抱紧玩具 | 小吉视线 | 同步声 |
| 1.2–2.0s | 停顿 | 手伸到一半停住 | 后退半步 | 两只小爪 | 静音 |
| 2.0–3.5s | 环境声 | 收手 | 耳朵放松 | 皮皮反应 | L-cut |
```

### 表演规则

1. 每句关键对白标记语义重音，并让画面焦点服务该词传递的信息。
2. 说话者主动作和倾听者主反应不得同时抢夺注意力；优先按“信息 → 反应 → 确认”排序。
3. 新角色、新道具、新规则或因果变化出现后，保留至少一个可见识别或反应节拍。
4. 除非刻意制造打断，不在语义关键词尚未说完时切镜。
5. 长对白先验证正常语速，再决定延长镜头、拆分表演节拍或延长成片；禁止加速语速掩盖时长冲突。
6. 标记声音剪辑：同步声、画外音、声音桥、J-cut（声音先于画面进入）、L-cut（声音延续到下一镜）或静音。
7. 一个节拍只允许一个主表演意图；动作、眼神、耳朵、嘴形和手势必须指向同一意图。

## 四、儿童剧对白语速

### 目标区间

普通对白的实际发声速度尽量保持在 **2.0–2.33 个可发音字/秒**。

- `2.0 ≤ 语速 ≤ 2.33`：目标区间。
- `语速 > 2.33`：过快，必须延长对白时长、重新分配镜头时长或延长成片。
- `语速 < 2.0`：允许，但必须在节拍表中说明停顿、强调、口吃、哭腔、唱念或低龄理解留白的原因。

唱歌、集体口号、哭喊、拉长音和明确的节奏化念白不机械套用普通对白区间，但必须按实际演出或试读时长填写。

### 计数口径

1. 只计算实际发声内容，不计算说话者姓名、冒号、标点和舞台说明。
2. 每个实际读出的中文汉字按 1 个可发音字计算。
3. 括号、方括号内默认视为舞台说明并排除；若括号内容需要发声，先移到对白正文再计算。
4. 阿拉伯数字、英文缩写和符号必须先展开成实际中文读音，再执行计算。
5. 叹词、拟声词和笑声只要实际发声，就按读出的汉字计数。

### 计算公式

```text
语速 = 可发音字数 ÷ 对白实际发声时长
最快目标时长 = 可发音字数 ÷ 2.33
最慢目标时长 = 可发音字数 ÷ 2.0
```

目标时长向上取到 0.1 秒，避免通过小数舍入把语速推到上限之外。

示例：“让我看看”共 4 个可发音字，目标发声时长约为 1.8–2.0 秒。

### 对白时长与镜头时长分离

对白发声时长只覆盖实际说话时间；镜头时长还要包含必要的动作准备、倾听反应、停顿和剪辑余量：

```text
镜头时长 ≥ 对白发声时长 + 前置动作 + 倾听反应 + 必要停顿
```

不得用整个镜头时长直接计算对白语速，否则静默表演会把对白误判为过慢。

### 机械校验

使用：

```bash
python3 scripts/dialogue_timing_check.py --text '小吉：“让我看看。”' --duration 1.8
```

输出必须包含可发音字数、语速、目标时长区间、状态和警告。出现数字或拉丁字母时，先按实际读音改写输入。

## 五、提交前机械门禁

量化评分前依次执行：

1. **对白门禁**：覆盖率 100%，删句、缩写、改写、错序、错配说话者均为 0；普通对白无未处理的过快项。
2. **空间门禁**：轴线、角色屏幕侧、视线、出入口和道具状态连续。
3. **表演门禁**：关键对白具有镜内节拍，语义重音、说话者动作和倾听者反应不抢焦点。
4. **页面映射门禁**：页面、宫格、镜号和对白 ID 无遗漏、重复或错序。
5. **视觉门禁**：图片数量、画幅、角色锚点、视觉模式和静态提示词符合配置。

任一硬门禁失败，直接进入下一轮修改。全部门禁通过后才进入四级量化评分。

统一终止逻辑：

- 总分达到 90 且所有层级达到合格线：通过。
- 总分低于 90 或任意层级未达线：进入下一轮修改。
- 第 5 轮仍未通过：强制终止，输出当前最佳版本、未通过项和改进建议。
