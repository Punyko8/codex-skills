## 一、先锁定任务配置

拆镜前记录故事板交付模式、视觉模式、画幅和是否需要视频提示词。用户未指定时，使用 `group-sheet + gray-rough + 16:9`。

### 故事板交付模式

无论使用哪种模式，每个生产段都必须对应 4–6 个静态分镜格：

- `shot-card`：每格单独输出一张图；一个生产段共 4–6 张。
- `group-sheet`：一个生产段输出一页 4–6 宫格合页。
- `hybrid`：保留每段 4–6 宫格合页，并把关键揭示、情绪转折或复杂调度格另做单张。

### 视觉模式

- `pure-line`：纯白底、纯黑轮廓线；禁止灰调、灰洗、色块、阴影、排线和实心填色。
- `gray-rough`：纯白或中性浅灰纸面，黑白中性灰动画粗草；禁止任何彩色色相和完整明暗塑造。

## 二、生产段：一次视频生成任务

### 定义与字段

“段”只表示一次 4–15 秒的视频生成任务，不等于文学段落、场景、单镜头或完整短事件。一个短事件可以拆成多个生产段；一个生产段内允许切换机位、景别、角度和镜头。

分镜表必须把 `段`、`段类型` 放在 `镜号` 前。段号按整集使用 `段001`、`段002`……连续编号，跨场景、章节和上下集不重置；镜号也按整集连续编号，不随新段重置。同一段的每个镜头行都重复填写相同段号和段类型，禁止留空或合并单元格。

不得另建段级生产总表；段信息只出现在分镜表的逐镜行、页面映射和逐段视频提示词中。

段类型只能使用：

| 段类型 | 定义 | 常规镜数 |
|--------|------|----------|
| `单镜连续` | 一次生成任务内只有一个连续镜头 | 必须 1 镜 |
| `多镜叙事` | 连续时空内用少量镜头完成一个局部进展 | 通常 2–3 镜 |
| `快速切镜` | 按剪辑顺序快速推进同一连续事件 | 通常 4–6 镜 |
| `纯转场` | 只负责相邻场景之间的转换 | 通常 1–6 镜 |
| `时间蒙太奇` | 用时间跳跃压缩过程 | 通常 3–6 镜 |

镜数为软上限：超过 6 镜通常拆段；只有用户明确要求特殊快速蒙太奇时才可突破，并在校验清单中标明 `special_montage`。

### 时长硬门禁

1. 相同段号下所有镜头时长之和就是段总时长；不得新增重复的“段总时长”列。
2. 所有段类型的段总时长都必须在 4–15 秒内，无例外；段内单镜可以短于 4 秒。
3. 不足 4 秒时，优先与相邻、同场景且功能相容的内容合并；仍不适合合并时，只补建立、动作完成或反应所必需的节拍。
4. 单镜独立段的自然内容不足 4 秒且不宜合并时，镜头时长直接写 `4s`。在既有“剪辑点”栏写“后期建议保留 Xs”以及必须保留的动作起止范围；不得为此增加新列。
5. 超过 15 秒时，在自然切镜、语义停顿或动作完成点拆段。

机械检查用 JSON 镜头行，不是新生产总表：

```json
[
  {
    "segment": "段001",
    "segment_type": "单镜连续",
    "shot": 1,
    "duration": 4,
    "scene": "S01",
    "trim_to": 2.5,
    "edit_note": "后期建议保留2.5s，保留抬头到眨眼完成"
  }
]
```

JSON 必填 `segment`、`segment_type`、`shot`、`duration`；按需加入：

- `scene`：场景 ID。
- `special_montage`：用户明确要求超过 6 镜的特殊蒙太奇时为 `true`。
- `time_evidence`：时间蒙太奇所用证据类型数组。
- `dialogue_continues_across_jump`、`sound_crosses_segment`：发现对应违规时为 `true`。
- `has_new_dialogue`、`has_educational_point`、`has_new_conflict`：纯转场承担对应内容时为 `true`。
- `trim_to`、`edit_note`：把“剪辑点”中的裁后时长与保留动作结构化给脚本，不是分镜表新列。

运行：

```bash
python3 scripts/segment_timing_check.py --input segments.json
```

### 场景与时间边界

1. `单镜连续`、`多镜叙事`、`快速切镜`和`时间蒙太奇`不得跨场景。
2. `纯转场`可跨相邻两个场景，但唯一任务必须是转场，不得承担新对白、教育点或新冲突。
3. 除 `时间蒙太奇`外，段内时间必须连续。
4. `时间蒙太奇`必须使用 3–6 个快速镜头，并至少给出两类可见时间证据，如光线、钟表、环境、道具完成度或角色状态变化。连续对白不得跨越时间跳跃。

## 三、故事板页面与宫格映射

每个生产段映射 4–6 格，禁止先画后补：

- 段内 4–6 镜：严格按剪辑顺序一镜一格。
- 段内 2–3 镜：每镜至少一格，其余格表现关键动作、倾听反应或终态。
- 段内 1 镜：4–6 格表现同一镜头内部连续动作节拍，不虚构新镜头。
- `快速切镜`：严格一镜一格，不调整剪辑顺序。

每格必须标注段号、镜号和镜内节拍：

```markdown
页面ID：P001
交付模式：shot-card / group-sheet / hybrid
对应生产段：段001
段类型：多镜叙事
对应镜号：1–3
宫格数：5
阅读顺序：左上 → 右上 → 中左 → 中右 → 下
逐格映射：格1→段001/镜1/起势；格2→段001/镜1/反应；格3→段001/镜2/动作；格4→段001/镜2/终态；格5→段001/镜3/确认
对应对白ID：D001–D003
```

每格只呈现一个静态瞬间。不得要求段级首帧、尾帧，也不得把相邻段参考图传递作为硬交付；连续性由分镜表中的角色位置、空间关系和道具状态控制。

## 四、场面调度与空间连续性

### 场景空间表

每进入一个新场景，先输出场景空间表：

```markdown
| 场景ID | 主轴线 | 角色屏幕侧 | 出入口 | 关键道具位置 | 初始状态 |
|--------|--------|------------|--------|--------------|----------|
| S01 | 沙发—落地窗 | 小吉左、皮皮右 | 猫门在画面右侧 | 鳄鱼在沙发前 | 破洞、棉花外露 |
```

每个镜头必须填写：

- **场面调度**：谁从哪里移动到哪里；谁保持不动；动作先后顺序。
- **连续性锚点**：主轴线、角色屏幕侧、视线方向、出入口和关键道具方位。
- **道具状态**：镜头开始状态 → 镜头结束状态。

### 空间硬门禁

1. 未说明原因不得跨越 180 度轴线。越轴必须通过中性正面镜头、可见的摄影机过轴或角色穿越轴线完成。
2. 角色离画方向必须与下一镜入画方向相容；视线方向必须与被看对象的屏幕位置一致。
3. 道具结束状态必须成为下一镜开始状态；破损、开关、装入、取出、移动和所有权变化都要登记。
4. 同屏默认只有一个主要动作；其他角色只承担倾听、反应、等待或不争夺注意力的次要动作。
5. 任一空间硬门禁失败，直接打回。

## 五、表演节拍、对白与声音边界

每个含对白、连续动作或关键反应的镜头都必须建立镜内节拍：

```markdown
| 段内时码 | 镜号 | 声音 | 说话者表演 | 倾听者反应 | 画面焦点 | 声音方式 |
|----------|------|------|------------|------------|----------|----------|
| 0.0–1.2s | 1 | 小吉：“让我” | 身体前倾 | 皮皮抱紧玩具 | 小吉视线 | 同步声 |
| 1.2–2.0s | 2 | 小吉画外音：“看看。” | 手伸到一半 | 后退半步 | 两只小爪 | 本段画外音 |
| 2.0–3.5s | 2 | 停顿 | 收手 | 耳朵放松 | 皮皮反应 | 静音 |
```

### 表演与声音规则

1. 一句对白可以跨同一段内的镜头切换；按整句原文、总发声时长和语速档位核验。每镜标出承接的原文范围，说话者离画后写“本段画外音”。
2. 对白绝不跨段；所有旁白、画外音、环境声和音效也必须在所属段内开始并结束。禁止跨段 J-cut、L-cut 和声音桥。
3. 每句关键对白标记语义重音，让画面焦点服务关键词。
4. 说话者主动作与倾听者主反应不得同时抢焦点；优先按“信息 → 反应 → 确认”排序。
5. 新角色、新道具、新规则或因果变化后，保留至少一个可见识别或反应节拍。
6. 除非刻意打断，不在语义关键词尚未说完时切镜。
7. 一个节拍只允许一个主表演意图；动作、眼神、耳朵、嘴形和手势必须同向。

## 六、儿童剧对白语速

每句普通对白必须由写作者选择并填写 `语速档位`，质检者复核：

| 档位 | 可发音字/秒 | 边界 |
|------|-------------|------|
| `慢` | 2.0–2.33 | 两端包含 |
| `中` | 大于 2.33–2.8 | 下界不含，上界包含 |
| `快` | 大于 2.8–3.3 | 下界不含，上界包含 |

- 低于 2.0 允许，但必须说明停顿、强调、口吃、哭腔、唱念或低龄理解留白原因。
- 高于 3.3 直接打回；不得用超快语速掩盖时长冲突。
- 唱歌、集体口号、哭喊、拉长音和节奏化念白不机械套档，但必须填写实际试读时长和例外说明。

### 计数与时长

1. 只计算实际发声的中文汉字；不计算说话者姓名、标点和舞台说明。
2. 括号、方括号内默认不发声；需发声的内容先移入正文。
3. 数字、英文缩写和符号先展开成实际中文读音；叹词、拟声词和笑声按读出的汉字计数。
4. `语速 = 可发音字数 ÷ 对白实际发声时长`。
5. 对白发声时长只覆盖说话时间；镜头时长还要另加前置动作、倾听反应、必要停顿和剪辑余量。

例如 16 字在 6 秒内为 2.67 字/秒，属于 `中`；33 字在 10 秒内为 3.3 字/秒，属于 `快`。

运行机械校验：

```bash
python3 scripts/dialogue_timing_check.py \
  --text '皮皮：“让我看看。”' \
  --duration 1.8 \
  --tier 慢
```

低于 2.0 时增加 `--reason '皮皮哽咽后留出理解停顿'`。档位不匹配、无理由低于 2.0 或高于 3.3 均返回失败。

## 七、逐段 AI 视频提示词

AI 视频提示词必须按生产段输出，一段提示词只对应一次生成任务；禁止按镜头拆成多个生成任务。每段写清总生成时长、段类型、镜号和按秒切换顺序：

```markdown
### 段001｜多镜叙事｜6s｜镜1–镜3

0.0–2.0s（镜1）：儿童眼高中景固定，皮皮从地毯站起……
2.0–4.0s（镜2）：硬切近景，皮皮指向破洞玩具，说……
4.0–6.0s（镜3）：切双人中景，爸爸蹲下倾听……
声音边界：本段对白、画外音、环境声和音效全部在 0.0–6.0s 内开始并结束；无跨段声音。
连续性：皮皮画面左侧，爸爸右侧；玩具从皮皮怀中保持到段尾。
```

段提示词的内部时码之和必须等于分镜表中该段镜头时长之和，并严格保持镜号顺序。视觉分镜图与 AI 生图提示词仍按宫格/镜头/镜内节拍输出，不与逐段视频提示词混用。

## 八、提交前机械门禁

量化评分前依次执行：

1. **对白门禁**：覆盖率 100%，删句、缩写、改写、错序、错配说话者均为 0；语速档位必填且无不匹配、无理由偏慢或超过 3.3 的项目。
2. **生产段门禁**：段号和镜号整集连续；段类型逐行重复且合法；段总时长均为 4–15 秒；普通段不跨场景；时间蒙太奇证据充足；纯转场不夹带新剧情；所有声音不跨段。
3. **空间门禁**：轴线、角色屏幕侧、视线、出入口和道具状态连续。
4. **表演门禁**：关键对白具有镜内节拍，语义重音、说话者动作和倾听者反应不抢焦点。
5. **页面映射门禁**：每段 4–6 格；页面、宫格、段号、镜号、镜内节拍和对白 ID 无遗漏、重复或错序。
6. **视频提示词门禁**：逐段输出，一段一次任务；内部镜头时码、切换顺序和段总时长与分镜表一致。
7. **视觉门禁**：图片数量、画幅、角色锚点、视觉模式和静态提示词符合配置。

任一硬门禁失败，直接进入下一轮修改。全部门禁通过后才进入量化评分。总分达到 90 且各层级达到合格线才通过；第 5 轮仍未通过时强制终止并输出当前最佳版本、未通过项和改进建议。
